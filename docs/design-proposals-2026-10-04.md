# RuBii ポートフォリオ デザイン刷新案

作成日: 2026-10-04
資料バージョン: 0.2.4
状態: 比較・検討用。採用案は未決定。サイトへの実装は次の段階。

追記（2026-10-04）: ユーザーから、B案をピアノ楽譜主体で発展させたいとの意向があった。[小さな音符の動き・ホバー演出・情報量の制御に関する追加提案](design-b-piano-interactions.md)を作成した。以下の4案は比較時点の記録として残す。

最新の方向性: [B案 改訂 — 音楽空間としてのポートフォリオ](design-b-music-space.md)。ピアノ・五線・音符を情報配置と操作へ一体化し、スマホはアニメーション演出なしとする。

## 1. 今のデザインから引き継ぐもの

現在のローカル実装と要件書をもとにした提案。以下の「良さ」はデザイン上の評価であり、アクセス解析や利用者調査の結果ではない。

| 現在の特徴 | 引き継ぐ理由 | 刷新する余地 |
| --- | --- | --- |
| 生成りの背景、淡い紫・青、柔らかな光 | 透明感のあるピアノや儚い歌詞という紹介文に合う | 光を単なる背景から、作品を見せる構成へ広げる |
| 大きなRuBiiの文字と明朝・セリフ体 | 名義が記憶に残り、静かで上品な印象をつくる | 文字の位置、大きさ、画像との関係を大胆に変える |
| 広い余白と細い罫線 | 作品と文章を落ち着いて見られる | 各区画の同じリズムを崩し、見せ場に強弱をつける |
| Works / About / Contactと縦スクロール | 目的のページへ迷わず移動できる | 表現を変えても、操作の分かりやすさは共通にする |
| 代表曲と制作相談の二つの入口 | リスナーと依頼主の両方に応えられる | 最初の画面に試聴のきっかけを置く |
| 新しい人物アイコン | 青い髪、暖かな光、表情にRuBiiらしさがある | 単なる小さなロゴから、色やレイアウトの起点へ育てる |

現状は「大きな名義 → 代表曲 → お知らせ → 紹介 → 相談」の整然とした構成。4案では、配色だけでなく、最初に何を見せるか、スクロールのリズム、作品との出会い方を変える。

## 2. 4案の比較

以下の比較は本提案内での相対評価。制作負荷は採用する演出や追加素材によって変わる。

| 案 | 一言でいうと | 主役 | 現状とのつながり | 大きく変わる部分 | 向いている優先事項 | 制作負荷 |
| --- | --- | --- | --- | --- | --- | --- |
| A 光のギャラリー | 光の層を通して作品に出会う | 光と代表曲 | 最も強い | 重なりのある大きな構図、左右非対称の作品展示 | 今の透明感を発展させ、印象を強める | 中 |
| B 音楽の装丁 | 一冊の作品集を読む | 文字と作品情報 | 強い | 大胆な文字組み、縦長の見出し、誌面のような作品一覧 | 作品・担当・経歴を分かりやすく伝える | 中 |
| C 夜のリスニングルーム | 一曲に向き合う静かな舞台 | 試聴する体験 | 色は変わるが、余白と静けさは継承 | 濃紺の冒頭、明暗の切り替え、大きなプレーヤー | 音楽の世界観と代表曲を強く印象づける | 中〜高 |
| D るびぃのアトリエ | 作り手と作品が並ぶ場所 | 人物アイコンと活動 | 色と余白を継承 | 人物中心の構図、左右で役割を分けた画面 | ボカロPとしての親しみやすさと個性を出す | 中 |

## 3. A案 — 光のギャラリー

**現在の淡い球体を、画面全体に広がる「光の層」へ発展させる。** 白い展示室に、薄いガラスや光の輪が重なっているような構成。今の方向性を最も自然に引き継ぎながら、作品画像を大きな見せ場にする。

### 最初の画面

左側に画面幅の約半分を使った「RuBii」。右側に横長の「雨を待つ」の画像を置き、名義の下端と画像の上端を少し重ねる。背後には大きな楕円の光と、半透明の平面を2〜3枚だけ配置する。本文とボタンは無地の領域に置く。

代表曲の画像と再生ボタンが最初から見えるため、スクロール前にも作品に触れられる。制作相談はヘッダーと名義下の控えめなリンクから入れる。

```text
［アイコン RuBii］             Works  About  Contact

     R u B i i              ╭── 淡い光の層 ──╮
     感情豊かな音楽を        │                │
     お届けします。     ┌─────────────────────┐
                       │ 雨を待つ の作品画像  │
     ［作品を聴く］     │        ▶ 再生       │
     制作のご相談       └─────────────────────┘
                             作詞・作曲 / 知声
──────────────────────────────────────────────
     大きな代表作 → 小さな作品2点 → 活動情報
```

### ページ全体・Works・About・Contact

- トップは「名義＋代表曲 → 選んだ作品最大3点 → About → News → Contact」。作品の枚数が少ない間は実際に登録された分だけ表示する。
- 作品画像の大小を交互にし、上端も少しずらす。数枚を見るだけで展示を巡るようなリズムをつくる。
- Works全件は整列した2列の一覧に戻し、ジャンルフィルターを上部に置く。曲名・担当・起用先は画像の下で必ず読める。
- Aboutは人物アイコンを角のある白い額のように見せ、その後ろに淡い紫の面を少しずらす。
- Contactは横幅いっぱいの生成りの区画と大きな日本語見出し。フォーム欄は白地に固定して読みやすくする。

### 色・文字・動き

| 役割 | 色・表現 |
| --- | --- |
| 地色 | 生成り `#F8F7F4` |
| 文字 | 濃い青灰 `#252A37` |
| 光 | ラベンダー `#D8D1E9`、青灰 `#BCCBDD` |
| ごく小さな差し色 | アイコンの光を拾った杏色 `#E9C5AE` |
| 文字 | 名義・曲名は現行のセリフ体／明朝、本文・操作はゴシック |

光はCSSで静止画として成立させる。動きを加えるなら、初回表示時の短いフェードと画像への小さな拡大だけ。装飾のために文字を読みにくくしたり、WebGLを必須にしたりしない。

### スマートフォン

名義 → 紹介文 → 代表曲画像の順に縦へ並べる。画面高いっぱいの固定ヒーローを避け、代表曲の上端が自然に見える長さにする。光は右上の一部だけ残し、画像と文字の重なりを解除する。

### 素材と留意点

既存の作品画像と人物アイコンで着手できる。光の装飾を増やしすぎると現状と同じ「抽象的なきれいさ」に留まるため、作品画像の大きさと配置を変えることが刷新の中心になる。

## 4. B案 — 音楽の装丁

**ポートフォリオを、一冊の楽譜集・作品集のように組み直す。** 余白とタイポグラフィという現在の強みをさらに押し出す案。大きな文字、細い罫線、ページ番号のような情報で、静かなまま強い印象をつくる。

### 最初の画面

左端に小さな「RuBii / Composer」。中央には「感情豊かな／音楽を／お届けします。」を大きな明朝体で3行に組む。右に小さな人物アイコン、下に「雨を待つ」の横長画像をページ幅いっぱいに見せる。名義だけが大きかった現状から、音楽のメッセージを主役に切り替える。

```text
［RuBii］                      Works  About  Contact
────────────────────────────────────────────────
     感情豊かな                         ［人物］
     音楽を                       るびぃ / RuBii
     お届けします。                    作詞・作曲

     01 ─ 雨を待つ                         ▶ 聴く
     ┌──────────────────────────────────────┐
     │              作品画像                │
     └──────────────────────────────────────┘
     作詞・作曲  /  知声  /  オリジナル楽曲
────────────────────────────────────────────────
     02 ─ おもかげ      ｜ 制作のご相談 →
```

### ページ全体・Works・About・Contact

- トップは「大きなメッセージ → 代表曲 → 新しい作品 → 活動の記録 → About → Contact」。見出しと画像の間に大胆な空白を置く。
- Worksは横長の行を積む。左から「画像」「曲名・担当・起用先」「年・ジャンル・試聴」の順に読み取れる配置にする。
- 一覧の装飾番号は表示順を示すものとし、作品数や実績を誇張する数字にしない。ジャンルで絞り込んでも作品IDは変えない。
- Aboutは人物画像と本文を見開きのように左右へ配置。経歴が確定したら、細い罫線を使う年表を追加できる。
- Contactは書簡のような縦一列。説明、入力欄、送信の順をそろえ、相談のしやすさを重視する。

### 色・文字・動き

| 役割 | 色・表現 |
| --- | --- |
| 地色 | 紙を思わせる白 `#F5F1E9` |
| 文字 | インク色 `#292D38` |
| 区切り | 温かい灰 `#D5D0C8` |
| 注釈・選択状態 | くすんだ紫 `#756A8C` |
| 文字 | 日本語の明朝を大きく使用。本文は横書きゴシック、日付は小さな数字 |

縦書きはPCの短い区画名だけに限定する。本文や曲名を無理に回転させない。動きはリンクの下線と短いフェードに絞り、文字組みそのものを見せ場にする。

### スマートフォン

見開きを一列に戻し、縦書きを横書きに切り替える。大きなコピーは改行位置を調整し、本文は通常の大きさに保つ。作品は画像 → 曲名 → 担当・起用先 → 試聴の順に並べる。

### 素材と留意点

追加の大きな画像がなくても成立し、作品が増えたときも一覧を整理しやすい。一方で、文字が主体になる分、長い仮文章をそのまま大きく載せると冗長になる。見出しは現行文を仮に使い、採用時に本人の言葉として調整する。

## 5. C案 — 夜のリスニングルーム

**最初の一画面を、代表曲のための静かな舞台にする。** 現在の透明感を夜の色へ置き換える。濃紺の冒頭から生成りの作品一覧へ切り替えることで、色と空間に大きな変化をつくる。

### 最初の画面

濃紺を背景に、薄い光の輪と大きな「RuBii」を中央へ配置。その下に「雨を待つ」の画像と明確な再生ボタン、曲名、担当をまとめる。画像は背景全面へ引き伸ばさず、主役の一枚として表示する。

```text
╔══════════════ 濃紺の背景 ═══════════════════╗
║［人物 RuBii］          Works About Contact ║
║                                            ║
║                  R u B i i                 ║
║       感情豊かな音楽をお届けします。        ║
║          ┌─────────────────────┐           ║
║          │   雨を待つ  ▶ 聴く  │           ║
║          └─────────────────────┘           ║
║            作詞・作曲 / 知声                ║
╚════════════════════════════════════════════╝
          ↓ 生成りの作品一覧に切り替わる
［全て］［ポップス］［バラード］［エレクトロ］
```

### ページ全体・Works・About・Contact

- トップは「代表曲の舞台 → 明るい作品一覧への入口 → About → News → Contact」。試聴を最も目立つ行動にする。
- ページ冒頭の再生は現行と同様、利用者が押した時にYouTubeまたはSoundCloudの埋め込みを表示する。自動再生はしない。
- WorksとContactの本文領域は生成りを基本にし、長い一覧やフォームは明るい画面で読めるようにする。
- Aboutは小さな人物画像を濃紺の余白に置き、その下で明るいプロフィール本文へ切り替える。
- 依頼の入口は冒頭のナビゲーションに常時置き、試聴後にも「このような音楽の制作について相談する」という意味が伝わる導線を配置する。文言は採用時に確定する。

### 色・文字・動き

| 役割 | 色・表現 |
| --- | --- |
| 冒頭の地色 | 夜の紺 `#18202D` |
| 冒頭の文字 | 月白 `#F4F1EC` |
| 光 | 青紫 `#A8B5D5`、淡い藤 `#C7BBD9` |
| 下層の地色 | 現行の生成り `#F8F7F4` |
| 文字 | 名義と曲名は細めのセリフ体。ボタンは判別しやすいゴシック |

光の輪は静止を基本にし、採用する場合だけゆっくりした変化を加える。スクロールを止める演出や自動的な全画面切り替えは使わない。飾りの波形を実際の音声に反応するように見せかけない。

### スマートフォン

ナビゲーション → 名義 → 再生画像の順で、最初の画面から曲名と再生操作へ到達しやすくする。ブラウザの高さに合わせた過大な余白を作らず、作品画像の16:9を保つ。暗い背景でもボタンの境界を明確にする。

### 素材と留意点

既存の「雨を待つ」の画像で試作できる。実際の曲の印象と演出が合うかは、採用前に試聴しながら確認する。暗い画面は現在からの変化が大きいため、作品一覧まで全面を暗くするかどうかは初稿を見て判断する。動画の常時読み込みや背景動画を加える場合は別途検討が必要。

## 6. D案 — るびぃのアトリエ

**新しい人物アイコンを起点に、「誰が作っている音楽か」が伝わる構成へ変える。** 現在の上品さを保ちながら、青い髪、暖かな光、緑の服から取った色を小さく散らし、作り手の温度を加える。

### 最初の画面

PCでは左を作り手の紹介、右を作品と活動の領域にする。左に正方形の人物画像と大きな名義、右に「雨を待つ」と最新のお知らせを置く。画像の後ろに淡い色の長方形を少しずらして重ねる。

```text
［RuBii］                      Works About Contact
────────────────────────────────────────────────
   作り手の紹介              │  まずはこの曲。
                             │  ┌────────────────┐
   ┌──────────────┐          │  │ 雨を待つ ▶     │
   │ 新しい人物画像│          │  └────────────────┘
   └──────────────┘          │  作詞・作曲 / 知声
        RuBii                │
   感情豊かな音楽を。        │  NEWS ────────────
   ［制作のご相談］          │  おもかげを公開
                             │  すべての作品 →
────────────────────────────────────────────────
        得意な音楽 → プロフィール → Contact
```

### ページ全体・Works・About・Contact

- PCの左側の紹介を、トップ冒頭の作品・News区画の間だけ追従させる。以降は横幅全体を使う。ページ全体を左右別々にはスクロールさせない。
- Worksは整列した作品カードに、色のついた小さなジャンルラベルを添える。色だけで分類せず、ポップス・バラード・エレクトロの文字を必ず併記する。
- Aboutは人物画像、短い自己紹介、音楽の特徴、経歴という順番。経歴は本人が確定した内容だけ載せる。
- Contactは小さな人物アイコンを見出しの隣に置き、「この作り手へ相談する」感覚をつくる。フォームの仕様は現行を使う。
- アイコン画像を全カードへ繰り返さず、作品そのものの絵柄と競合しない使い方にする。

### 色・文字・動き

| 役割 | 色・表現 |
| --- | --- |
| 地色 | 現行の生成り `#F8F7F4` |
| 文字 | 青みのインク `#293344` |
| 主な差し色 | 髪を起点にした青 `#697FAF` |
| 小さな色面 | 杏色 `#EAC8A0`、薄い青緑 `#C8DDD4` |
| 文字 | 大きな名義は現行のセリフ体。本文は親しみやすい横書きゴシック |

色面は原則3色までに抑える。カードを押せそうに見せる動きは、実際にリンクや再生操作がある領域だけに使う。

### スマートフォン

左右の分割と追従を解除し、人物画像を160〜220px程度にして、名義・短い紹介・代表曲を順に置く。人物画像だけで最初の画面を使い切らないようにする。

### 素材と留意点

人物アイコンは現在400×400px。PCでも表示幅を原則400px以下にし、背景いっぱいには拡大しない。高精細画面向けに大きく使う場合は、元の高解像度データが必要になる。現行の人物イラストは暖かく明るいため、曲の儚さとのバランスを、生成りの面積と落ち着いた文字色で取る。

## 7. 全案で維持する使いやすさ・運用

### 作品と問い合わせ

- 日本語を基本に、上部のWorks / About / Contactを維持する。
- 縦スクロールで閲覧でき、横スクロールやドラッグだけを必須操作にしない。
- 作品には曲名・担当・起用先を常時表示する。空欄の情報は創作しない。
- ジャンルはポップス・バラード・エレクトロの3種類。未登録作品や実績を見栄えのために増やさない。
- トップは少数の選定作品、Worksは全作品を探す場として設計する。
- 約100作品になった場合も、埋め込みプレーヤーを一斉に読み込まず、操作された作品から読み込む。
- 作品数が増えて探しにくくなった場合、検索と24件程度の分割表示を追加候補にする。これは今回の確定仕様ではない。
- Formspreeの接続とXへの連絡導線を維持する。フォームの再接続や受信先変更はデザイン変更に含めない。

### 表示・操作

- 文字と背景のコントラストを実装時に測定し、通常の本文は4.5:1以上を目標とする。淡い色は主に装飾面へ使う。
- ボタンの押せる範囲は原則44px以上とし、キーボード操作時のフォーカスを見えるようにする。
- 動きを減らすOS設定に対応し、装飾を止めても内容が読める構成にする。
- スマートフォンで画像・曲名・担当・再生操作の順番が自然に読めることを確認する。

### 更新方法

- Astro + Tailwind + JSON、GitHub Pagesの構成を継続する。全案とも既存の仕組みの上で実装できる想定。
- 曲名・担当・起用先・説明・リンクなどは現在のJSONと編集ページから更新できる状態を保つ。
- 名義、プロフィール、ニュース、人物アイコン、作品画像など既存の素材で初稿を作る。未登録の経歴を必須にしない。
- 複数のトップ掲載作品を本人が選べるようにする場合は、現在の代表曲フラグとの役割を整理し、JSONと編集ページを同時に拡張する。
- 既存URLを保ち、各ページの `/portfolio/` 以下のリンクを確認する。
- 今回は提案資料のみ。既存の画面、未コミットの編集内容、公開サイトは変更しない。コミットとプッシュは本人が行うという直近の方針を継続する。

## 8. 推奨する進め方

**最初の候補はA案。** 現在の「淡い色・透明感・余白」を最も残しやすく、作品画像の位置と大きさを変えることで、見た目にも十分な刷新を出せる。依頼主に作品情報を端的に見てもらう点を重視するならB案、試聴体験を中心に置くならC案、作り手としての存在感を育てるならD案が合う。

組み合わせる場合は、A案のトップとB案のWorks一覧が自然。4案の特徴を均等に混ぜるより、主案を一つ選び、別案から一要素を取り入れる。

採用前に選ぶ項目は次の3つ。

1. **主役**: 作品と光（A）／文字と作品情報（B）／試聴体験（C）／作り手（D）。
2. **色の幅**: 現在の明るさを基本にするか、濃紺の冒頭を取り入れるか。
3. **人物アイコンの存在感**: 小さな署名として使うか、トップの主役にするか。

主案を選んだ後は、トップとWorksのPC・スマートフォンの静的な初稿をローカルで作る。構図を確認してからAbout・Contactへ展開し、動きは最後に加える。採用決定までは現行UIを置き換えない。
