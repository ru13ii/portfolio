# Homeの五線譜の繰り返し表示 — 0.8.0

更新日: 2026-10-05。

## 依頼・原因

本人から、代表曲の歌詞開閉で背景の五線譜も動く問題の修正と、好きな五線譜のデザインがスクロール中も定期的に現れる表示を依頼された。対象はHome全体とし、従来の曲線・色・薄さを保持する。

0.7.1ではピアノの縦中央揃えだけを修正したが、MusicAirのSVGはmusic-room全体の高さに引き伸ばされていた。1280px幅では歌詞開閉で背景領域の高さが約710pxから1341pxへ増え、五線譜の位置・形と背景音符の配置基準も変わっていた。

## 実装・表示仕様

- 従来の5本の曲線を `src/assets/home-staves.svg` に移し、Homeだけに付ける `home-page` クラスのCSS背景として縦に繰り返す。曲線の座標・線色・透明度・太さは従来のSVGから保持する。
- 背景タイルは幅100%、高さ `clamp(420px,47.2222vw,680px)`。本文の高さと切り離し、歌詞を開閉しても起点・周期・形を変えない。スクロールとともに作品・プロフィールの余白・お知らせ・依頼導線へ現れる。固定背景やスクロール連動アニメーションは追加しない。
- Aboutの紙面・画像は不透明のまま保持し、外周の帯の背景色を半透明にして薄く五線譜を透かす。文字・リンク・再生・歌詞操作の上に装飾要素を重ねない。
- 背景音符の領域は画面幅から1440:680の比率で決め、歌詞で高さが変わる領域から切り離す。PCの既存の浮遊演出と画面外・非表示時の停止を保持する。スマホでは音符を非表示、五線譜は静止背景とする。
- Viteの `?no-inline` を使い、SVGを同一オリジンの外部ファイルとして出力する。GitHub Pagesの `/portfolio/` パスにも自動対応し、CSPへdata:等を追加しない。Works・About・Contact・編集ページの背景は変更しない。
- 機能追加としてpackage.json/package-lock.jsonを0.8.0へ更新する。作品JSON・本人の歌詞・経歴・制作年・依存バージョン・セキュリティ設定は変更しない。ローカル用資料・引き継ぎ資料・先行する文書整理は公開コミットから除外する。

## 検証

- Node.js 24で28件のテスト成功。本番パスのビルド・全5ページの成果物セキュリティ検査成功。既存CSPの属性禁止設定に伴う警告は継続し、保護は維持する。
- ローカルBrowserの1440・1280・1024・900・375pxで代表曲の歌詞を開閉。背景画像・起点・周期、ピアノ・再生エリアの座標とサイズが一致し、表示中の背景音符領域も変わらない。スマホでは音符領域は非表示。横はみ出しなし。
- タイルの高さは順に680・約604・約484・425・420px。歌詞を開くと後続のWorksのみ約630px下へ移動し、背景周期は変化しない。Homeの掲載作品の歌詞開閉でも同じ背景の起点と周期を確認。
- PCでトップ・Works・About外周・Journalのスクロール表示、スマホのWorks表示を目視確認。五線譜が繰り返し現れ、作品と文章は判読できる。WorksページにはHomeの背景が適用されないことを確認。
- 同一オリジンのSVGが本番パスで読み込まれ、背景として表示されることを確認。確認画像は一時フォルダーだけに保存する。実GitHub編集保存・フォーム送信は行わない。

公開処理の結果と公開後の確認は、公開対象外の引き継ぎ・作業記録へ追記する。
