# 歌詞の開閉表示・編集 — 0.7.0

更新日: 2026-10-05。

## 依頼と採用仕様

本人の依頼は「HomeおよびWorksの楽曲の歌詞をクリックで表示・非表示にしたい。歌詞データは本人が後から編集して載せる」。作品ごとに任意の自由文 `works[].lyrics` を持たせる。本人の既存文章・作品データは変更せず、歌詞の仮文も正本JSONに追加しない。価格・条件・問い合わせ設定には変更を加えない。

- Homeの代表曲は紹介の末尾、Homeの掲載作品とWorksは作品情報の末尾へ配置する。同じ作品の歌詞を共通データから表示する。
- 初期状態は閉じる。標準の `details/summary` で「歌詞を表示／歌詞を閉じる」を切り替える。複数の曲を独立して開閉できる。
- 空欄・空白だけ・項目未定義なら欄全体を表示しない。未入力時に「準備中」などの表示は増やさない。
- 改行・空行を保持する `white-space: pre-wrap` と長い行の折り返しを使う。歌詞全体を通常のページスクロールで読める。
- 編集ページに作品ごとの「歌詞（任意）」欄と説明を追加。新規作品も空の歌詞欄を持つ。既存JSONは項目なしで引き続き有効。
- 最大20,000文字。HTML・Markdownを解釈しない。入力・JSON書き出し・GitHub保存・ビルドで既存の共通データ検証を使う。
- マウス・タッチ・キーボードで開閉でき、読み上げ用に曲名を含む操作名を付ける。追加のJavaScript・開閉アニメーションは不要。

## 実装と安全性

`src/components/Lyrics.astro` をHomeの代表曲と `WorkRow.astro` から使う。本文はAstroの通常のテキスト式でエスケープし、`set:html` やDOMのHTML挿入を使わない。`src/lib/content-policy.js` の既存の文字列検証を歌詞にも適用する。CSP・URL制限・トークン保護・固定保存先・競合防止は維持する。

機能追加としてpackage.jsonとpackage-lock.jsonを0.7.0へ更新する。公開は歌詞機能のコード・テスト・使い方・仕様資料を対象にし、引き継ぎ用資料と確認用画像は含めない。先行するローカルの文書整理・削除は今回の公開コミットに含めない。公開前にmainの更新を確認し、本人が編集ページから保存した経歴文を取り込んで保持する。歌詞の仮文を公開したり、新しいテストメールを送ったりしない。
