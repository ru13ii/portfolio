# Aboutの経歴編集と料金表の検討 — 0.6.0

更新日: 2026-10-05

## 依頼と実装方針

依頼は「Aboutに経歴を簡単な文章編集で書けるようにする」「有償依頼の料金表を入れるべきか検討する」。既存の生成りの紙面・五線譜を思わせる余白、プロフィールカードと整合させる。

- Aboutのプロフィールと同じ紙面の下部に「MUSIC JOURNEY / 経歴」を配置。
- データは `site.careerText` の自由文1項目。年ごとの入力欄や並べ替え操作を増やさず、文章欄だけで編集できる。
- 編集ページに独立した「経歴」セクションを設置。改行と空行はそのまま表示。最大20,000文字。
- 内容を空欄・空白だけにすると見出しを含む経歴欄全体を非表示にする。
- 古いJSONで項目が未定義の場合も空欄扱いにして互換性を保つ。
- 表示はAstroの通常のテキスト式を利用し、HTML・Markdownを解釈しない。既存のCSP・トークン保護・共通データ検証を維持。
- 初期文は既存作品データの制作年・担当・起用先に基づく「雨を待つ（2024年、作詞・作曲）」「おもかげ（2026年、無色透名祭3、作詞・作曲）」。経歴文の自由入力は実装し、本人が後から編集できる。
- PCは見出しと本文を左右に配置し、スマホは縦に配置。新しいアニメーションは追加しない。

## 料金表の判断

**制作依頼を獲得する目的には、料金目安を掲載することを勧める。掲載場所はContactのフォーム手前。金額と作業範囲を決めてから公開する。**

この判断はRuBiiの目的と現在のサイト構成に基づく提案。問い合わせ数や成約率の増加を保証するものではない。今回の依頼は検討であり、料金や受注条件の決定ではないため、公開ページに未決定の料金表を設置しない。

### 掲載によって期待する効果

- 依頼者が予算を考えやすくなり、問い合わせ前の不安を減らせる。
- 「作詞・作曲・BGMの何を頼めるのか」を説明できる。
- 予算と制作範囲の食い違いを問い合わせ前に減らせる。

### 現段階の注意点

- 作曲のみ、作詞込み、編曲・音源制作まで含むかで作業量が異なる。本人が実際に受けられる範囲を先に決める。
- BGMは曲尺、ループの有無、必要曲数などで作業量が異なる。
- 最低料金だけを示すと「すべてその額で制作できる」と受け取られることがある。基準となる内容と追加料金の条件を一緒に書く。
- 他者の料金をそのまま採用せず、自分の制作時間と必要な報酬を基に決める。少数の掲載例は相場調査とは扱わない。

### 表示方式の比較

|方式|向く状況|RuBiiへの提案|
|---|---|---|
|問い合わせ後に個別見積もり|制作範囲・所要時間がまだ定まっていない|金額が未定の間は利用できるが、依頼者には予算感が伝わりにくい。|
|制作内容別の基本料金・目安＋個別見積もり|定型の依頼があり、内容に応じて調整したい|推奨。Contactにコンパクトな3項目程度を置く。|
|固定価格の複数プラン|作業範囲・納品物・修正回数を十分に定型化できる|現時点では必要性が低い。受注実績が増えてから検討する。|

### 公開案（項目のみ、金額は未決定）

|項目|一緒に示す条件|
|---|---|
|歌ものの作曲|曲尺、作曲のみか音源制作まで含むか、納品データ|
|BGM制作|基準の曲尺、ループ対応、音源形式|
|作詞|既存メロディへの作詞か、作曲とのセットか|

見出しは「制作料金の目安」。Contact内の紙面・罫線で3行程度にまとめ、WorksとAboutは作品・人物の理解に集中できる構成とする。独立した料金ページや料金の大きなカードは現段階では不要。

公開前に、基本金額、税込・税別の表記、基本料金に含む内容、修正回数、納期の目安、商用利用・配信・権利譲渡の扱いを本人が決める。権利関係は実際の受注時に双方で合意する事項であり、この提案だけで契約条件は確定しない。

文案は「制作内容・曲の長さ・使用用途に応じてお見積もりいたします。ご相談の際は、参考曲・ご希望の納期・用途・ご予算の目安をお知らせください。」。無料相談や無料修正の約束は、本人が決めるまでは追加しない。
