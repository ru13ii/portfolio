# 0.4.1 UI調整

> B案は0.5.0で正式採用済み。現行の配置・公開・送信・保存については [正式版への移行](production-adoption-0.5.0.md) とREADMEを参照。


作成日: 2026-10-04 / 対象: music-space

## 依頼と対応

| 依頼 | 対応 |
| --- | --- |
| 白鍵ホバーで黒鍵が欠ける | 白鍵のtransformで重なり順が変わっていた。黒鍵をナビゲーションの独立レイヤーに移動し、白鍵の上へ固定 |
| 黒鍵を3本にする | 4つの白鍵の全境界（25%・50%・75%）へ黒鍵を配置。メニューは実際の音階配列ではなくユーザー指定の構図 |
| クリック時の演出は不要 | active時の追加沈み込みを削除。ホバーとページの現在位置表示を維持 |
| 音符が出る演出をやめる | 操作から音符を生成するJS・CSSを削除 |
| Worksのジャンルは鍵盤以外に | 譜面フォルダーの索引をイメージした罫線・番号・選択下線のフィルターに変更。選択は即時反映 |
| Homeの停止ボタンは不要 | ボタンと手動停止処理を削除。PCでは既存の6音符が常時漂う |
| Works/About下部のContact導線を削除 | ContactCodaの呼び出しを削除。Homeの導線とメインメニューは維持 |
| Contactの試作案内文を削除 | 指定の段落だけ削除。ローカル確認処理はそのまま |

## 継続する条件

スマホ・タッチ中心・OSの動き削減では演出を停止する。画面外・非表示タブでは浮遊を一時停止し、見えるときに再開する。静止した音符の試聴ボタンと、既存の試聴ホバー反応は維持する。

元プロジェクト・current・作品JSONを変更せず、music-spaceのみ更新。package.jsonとlockのバージョンは0.4.1。
