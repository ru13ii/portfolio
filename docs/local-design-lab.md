# ローカル試作版の分離・比較・復帰

> B案は0.5.0で正式採用済み。現行の配置・公開・送信・保存については [正式版への移行](production-adoption-0.5.0.md) とREADMEを参照。


作成日: 2026-10-04 / バージョン: 0.4.1

## フォルダー

| 役割 | 場所 |
| --- | --- |
| 元プロジェクト | リポジトリのルート `./` |
| 作成開始時点の保存版 | 比較用フォルダー内の `current/` |
| 新デザインの作業場所 | 比較用フォルダー内の `music-space/` |

Gitで管理中のファイルと、除外されていない未追跡ファイルを複製したため、未コミットの文章・アイコン・デザイン資料も含みます。元プロジェクトと保存版の一致は、Labの `docs/source-snapshot.json` に記録したSHA-256で確認できます。

Gitの管理情報や認証情報、環境変数ファイルは複製していません。node_modulesは独立したコピーです。試作版から元のファイルや依存関係を参照するシンボリックリンクは作っていません。新デザインからは自動公開ワークフローも除いています。

## 比較する

保存版を4340番、新デザインを4341番で起動します。新デザインの `/compare.html` でトップ・Works・About・Contactを左右に表示できます。各ページはそれぞれスクロールします。PCは1280px、スマホは390pxの表示領域を縮小して比較します。

比較ページはルートURLでのローカル利用専用です。スマホ幅のフレームでは音符や押下のアニメーションが無効になります。

## この案をやめる場合

元プロジェクトをVS Codeで開き、そのまま作業を続けます。元のソースファイルを置き換えていないため、復元やGitの巻き戻しは不要です。試作版と比較用サーバーは、それぞれのフォルダーで `npx astro dev stop` を実行して停止できます。

`current` は比較専用の保存版として扱ってください。元プロジェクトを後日編集しても、この保存版は自動更新されません。

## この案を採用する場合

採用前に元プロジェクトの最新変更を確認し、変更した画面・スタイルを移します。作成後に元のJSONが更新されている可能性があるため、content.jsonを丸ごと上書きせずに内容を比較します。

この試作版はローカル限定のため、Contactは送信確認だけ、編集画面はJSON書き出しだけにしています。採用・公開時に、元プロジェクトの実送信とGitHub保存の処理を新しい画面へ接続して確認する必要があります。公開作業は今回行っていません。

## 実装の考え方

0.4.0では上面図の描き直し・左鍵盤・Home・PCの音符演出を追加した。最新の判断は [ピアノと演出の改訂](piano-refinement-0.4.0.md) を参照。

- ピアノのSVGの面に名前と紹介を載せ、五線を代表曲の再生操作へつなぐ。
- 共通のWorkRowで作品を並べ、曲名・担当・起用先を常時表示する。
- ナビゲーションとジャンルフィルターは鍵盤の区切りを使う。
- 音符のSVGは再生ボタンの一部。ボタンの外枠と文字は固定する。
- PCの演出は `min-width: 1024px`、`hover: hover`、`pointer: fine`、`prefers-reduced-motion: no-preference` のすべてが成立するときだけ有効。
- 小さい画面・粗いポインター・ホバー不可・動き削減では、疑似要素を含めアニメーションとトランジションを無効化する。
- 元の文章・曲・フォーム接続先などのJSONデータは複製時のまま保持する。
