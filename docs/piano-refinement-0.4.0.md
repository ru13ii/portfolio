## 今回の依頼

- 前案の図形がピアノに見えない。上面の画像を調査し、輪郭とピアノらしい黒を見直す。
- ピアノの左側に白鍵・黒鍵を描く。88鍵すべては不要。

## 画像の調査と判断

検索で見つかった [Vexelsの真上から見たグランドピアノ図](https://www.vexels.com/vectors/preview/74979/concert-grand-piano-top-view) をブラウザーで確認した。元図は鍵盤が下の向き。低音側の長い直線、尾部の丸み、高音側のくびれ、前面の鍵盤が揃っている。黒い面には明暗差と斜めの反射がある。参考画像そのものはダウンロード・転載していない。

実物の構造と比率の補助資料として [Steinway Model B](https://www.steinway.com/pianos/steinway/grand/model-b/) を参照。外周のリムを連続した構造として扱い、鍵盤と本体を別々の図形に見せないための手掛かりとした。特定メーカーの精密な寸法図やロゴの再現ではない。

### 輪郭の変更

前案は左右の区別が弱く、右端が上下に二度ふくらむ形だった。今回、鍵盤が左になるよう向きを整理し、次の順で一続きの輪郭を描き直した。

1. 左の鍵盤と直線的な前面。
2. 上側へ延びる長い直線の低音側。
3. 右上の丸い尾部。
4. 尾部から左下へ戻る高音側のくびれ。
5. 鍵盤の下端へ戻る肩の曲線。

SVGのviewBoxは940×680。縦横比を固定して拡縮する。本文の幅に合わせて輪郭を引き延ばさない。RuBiiの名義と紹介文は蓋の内側に置き、曲線の外側から代表曲へ五線をつなぐ。

### 黒色・鍵盤の質感

青灰色の一色塗りから、#030303〜#242426のほぼ無彩色の黒へ変更。広い面は暗く保ち、蓋の縁にだけ細い反射、面に弱い斜めの反射を置く。薄い外周線、蝶番、鍵盤との継ぎ目、赤褐色のフェルト、接地影を追加した。すべて自作SVG/CSS。

白鍵28本、黒鍵20本の4オクターブ相当。白鍵7本ごとに黒鍵を2本・3本で配置し、E-F/B-C間を空ける。白鍵は少し暖かい白、黒鍵は明るい上面と暗い側面で厚みを示す。鍵盤自体は装飾であり、音を鳴らす機能はない。

## メニューと操作

Home / Works / About / Contactを4つの白鍵として並べる。C-D-E-F相当の2本の黒鍵を間に追加。黒鍵は装飾で、リンクを覆ってクリックを妨げない。文字は黒鍵より下に置く。

Worksの4つのジャンルボタンにも同じ構造を使用する。PCのホバーで2px、押下で4px沈み込み、白鍵の影が浅くなる。現在位置・選択状態は色と下線で示す。Homeの現在位置は完全一致で判定し、全ページでHomeが選ばれることを避ける。

## 音楽が溢れる演出

| 演出 | 内容 | 制限 |
| --- | --- | --- |
| 空間の音符 | 6個の音符が7〜10秒周期でゆっくり上下・回転 | トップの余白のみ。画面外・非表示タブでは停止 |
| 操作から生まれる音符 | メニュー・フィルター・試聴に触れると3個が上昇して消える | 350ms以内の連続生成を抑制。各要素は最大1.4秒で削除 |
| 試聴の音符 | 850msの跳ね返り | 画像や本文は移動しない |
| ピアノの白鍵 | カーソルの下の鍵だけ明るくなり、2px動く | PCのみ。音声なし |
| 演出停止 | トップの「動きを止める」で停止・再開 | 状態をaria-pressedとラベルで通知 |

ユーザーの今回の依頼により、前案の「常時動かさない」「600ms以内」の条件をPCに限って更新した。カーソル追従、画面全体のパーティクル、音の自動再生は採用していない。

モーションは1024px以上・hover対応・fineポインター・OSの動き削減なしのすべてが揃った場合だけ有効。スマホ・タッチ中心・動き削減では、アニメーションとトランジションを疑似要素も含め停止。スマホは音符の環境レイヤーと停止ボタンを非表示にし、ピアノとメニューを静的に表示する。
