# Homeの歌詞開閉によるピアノ移動の修正 — 0.7.1

更新日: 2026-10-05。

## 依頼・原因・修正

本人の依頼は、Homeの代表曲の歌詞を表示するとピアノの位置がずれる問題を修正し、そのまま公開すること。

Homeの `.room-inner` は2カラムのCSS Gridで、`align-items: center` により縦中央揃えになっていた。代表曲の歌詞を開くと右側の高さが増え、共通の行の高さが再計算される。この結果、左側のピアノとその上の紹介文が下へ移動する。修正前の公開サイトでは、画面幅1440・1280・1024・900pxで約315pxの移動を確認した。375pxの縦並びでは発生しなかった。

`src/styles/piano-space.css` の `.room-inner` を `align-items: start` に変更する。左右を上端基準で配置し、歌詞は下方向に展開する。固定高さ・本文の切り詰め・JavaScriptでの位置調整は追加しない。ピアノの輪郭・寸法・色、スマホの縦並び、歌詞の改行・通常テキスト表示、CSP等のセキュリティ設定は維持する。

本人が追加した2曲の歌詞と制作年を含む、現在の `src/data/content.json` は変更しない。バグ修正としてpackage.json/package-lock.jsonを0.7.1へ更新する。引き継ぎ用資料・ローカルの文書整理は公開コミットから引き続き除外する。

## 検証

- Node.js 24で `npm test`: 28件成功。
- `GITHUB_REPOSITORY=ru13ii/portfolio npm run build` と `npm run check:dist`: 全5ページ成功。既存のCSPの属性禁止設定に伴う警告は継続し、保護は緩和していない。
- Browserで1440・1280・1024・900・375pxを確認。代表曲の歌詞を開く前・開いた後・閉じた後で、ピアノ・紹介文・再生エリアの座標とサイズが一致。ピアノの縦方向の移動量は全幅で0px。
- 歌詞はHomeのセクション内に収まり、後続のWorksセクションだけが本文の高さ分（今回の歌詞では約630px）下へ移動することを確認。横はみ出しなし。
- 歌詞・制作年・経歴を含む作品JSON、依存関係、セキュリティ設定は変更なし。ローカル用の文書・削除変更は公開対象に含めない。
- 追加の実GitHub保存やフォーム送信は行わない。公開反映後の確認は読み取りと歌詞の開閉だけで行う。
